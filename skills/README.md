# Skills für Lern-Apps

Zwei Skills für Claude Code, die für jede Schul-App gelten, nicht nur für dieses Repo:

- `lern-app-aus-schulmaterial`: aus Fotos von Lernzettel und Buch eine Übungs-App bauen (inklusive Rechtschreib-Einstellung je Klasse und Fach)
- `app-auf-github-pages`: App über GitHub Pages aufs iPad bringen, mit Anleitung für Eltern

## In einer neuen Umgebung installieren
```bash
mkdir -p ~/.claude/skills
cp -r skills/lern-app-aus-schulmaterial skills/app-auf-github-pages ~/.claude/skills/
```
Danach stehen beide Skills in jedem Projekt zur Verfügung.

Die Ordner liegen hier nur als Sicherung, weil `~/.claude/` in einer Cloud-Umgebung zurückgesetzt werden kann.
